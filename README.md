NKS Adaptive Safety Index

This repository contains the complete code and data for the paper:

"The NKS Adaptive Safety Index: A Time-Variant Probabilistic Framework for Climate-Resilient Structural Design" (under review at Structural Safety).

Files included:

NKS_Simulation.ipynb:
Full Jupyter Notebook with data cleaning, Gumbel fitting, and Monte Carlo simulation.

Miami_storms.csv, Chicago_storms.csv, LA_daily_max.csv: Cleaned, processed data used in the analysis.


NKS_Rigorous_Results_3Cities.png:
Final output graph.

Requirements:
Python 3.10+

Libraries:

pandas, numpy, scipy, matplotlib

How to run:

Open NKS_Simulation.ipynb in Jupyter Notebook and run all cells.
